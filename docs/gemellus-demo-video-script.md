# GEMELLUS - Demo Video Script v2
## 3 minuty | 2 rzeczy: pytanie o projekt + hiring pack

---

## CO POKAZUJEMY

Dwie rzeczy. Tylko dwie. Nic więcej.

1. **Pytanie o projekt** - kolega dzwoni do klona Mike'a z konkretnym problemem technicznym. Agent odpowiada z kontekstem i wskazuje kto w zespole może pomóc.

2. **Hiring pack** - kolega prosi agenta o wygenerowanie hiring packu, żeby znaleźć kogoś takiego jak Mike. Agent generuje dokument z realnych danych.

Nie demujemy redistrybucji pracy, nie demujemy analizy luk kompetencyjnych, nie demujemy czterech obszarów. Dwa pytania, dwa outputy, czysto i mocno.

---

## FORMAT

1. **Ekran** (screen recording) - aplikacja Gemellus
2. **Voiceover** - nagrany osobno, spokojny ton
3. **Kamera na kolegę** - dzwoni do agenta, rozmawia live

#### Pytanie 1: Problem w projekcie (0:30 - 1:10)

*Telefon dzwoni. Agent odbiera.*

**AGENT-MIKE:** "Hey, what's up?"

## WSKAZÓWKI DO NAGRANIA

**Rozmowa telefoniczna:**
- Nagraj 3 razy. Weź najlepszą
- Kolega mówi spokojnie, nie za szybko
- Nie przerywa agentowi
- Po odpowiedzi agenta na pytanie 2 - niech patrzy na ekran, cisza, zaskoczenie. To buduje moment
- Jeśli agent odpowie trochę inaczej niż w skrypcie - OK, autentyczność > perfekcja

**Voiceover:**
- Nagraj osobno, w ciszy, dobry mikrofon
- Ton: spokojny narrator, nie sprzedawca
- Jedyny moment voiceoveru PODCZAS rozmowy: po odpowiedzi na pytanie 1
- Reszta voiceoveru: przed i po rozmowie

**Montaż:**
- Scena 2 (setup): przyspieszone x2-x3
- Scena 3 (rozmowa): real-time, nie przyspieszaj
- Scena 4 (hiring pack): wolny scroll, daj czas na czytanie
- Przejścia: proste cut-y, zero efektów
- Muzyka: tylko ostatnie 10 sekund

**Układ ekranu podczas rozmowy:**
```
┌──────────────────────────────────────────────┐
│                                              │
│   ┌──────────────────┐  ┌────────────────┐  │
│   │                  │  │ AGENT ACTIVITY  │  │
│   │   KOLEGA         │  │                 │  │
│   │   Z TELEFONEM    │  │ (tool calls     │  │
```
