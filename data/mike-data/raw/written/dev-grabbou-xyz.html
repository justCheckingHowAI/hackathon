Challenges

At Callstack, we know enterprise apps aren't built in a day. As maintainers of the Community CLI and partners to enterprise teams, we see the real challenges:

High build times, zero reuse

Months just to integrate a third-party cloud vendor

A mixed tech stack that makes adding React Native feel like pulling teeth

and more...

"If you're not using framework, you're building one yourself"

React team

React Native Frameworks RFC

The React team set a solid foundation. But let's face it—no framework truly solves the complexity of modern enterprise codebases. We're here to change that with a smarter, cleaner approach to building robust apps.

That's why we decided to build a framework for enterprise.

Its main focus are:

Modular Design

add your supported platforms and plugins, and integrate existing tools

Self-Hosted

deploy on your own infrastructure

Incremental Adoption

easily migrate from Community CLI or an existing native app

Fortune 500 companies are using the Enterprise Framework today.
Check how we are getting it done

  • #1 - Migrate from Community CLI

    Apply a handful of changes to your project to migrate from the Community CLI

  • #2 - Configure GitHub Actions workflow

    Import our GitHub Action into your existing workflow or create a new one

  • #3 - Push changes and let it build in the cloud

    The native side of your app will be only built once. And later reused across all CI jobs and available to developers through the CLI in seconds

  • #4 - Download cached builds from the cloud

    The CLI will download cached builds from the cloud and make them available to developers. You can also build locally if you need to

  • #5 - Save time and unlock the impossible

    Reuse builds however you like: make development faster, speed-up E2E tests, download builds for testers instantly, on every commit
